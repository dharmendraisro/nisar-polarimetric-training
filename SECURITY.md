# Security Policy

## Reporting a security issue

Please do not report security vulnerabilities or exposed credentials through a public GitHub issue.

If the repository's GitHub Security Advisories feature is enabled, use a private security advisory. Otherwise, contact the maintainer privately through the contact information associated with the GitHub profile.

## Scope

Examples include:

- exposed credentials or tokens
- malicious code introduced into project workflows
- unsafe handling of user-provided files
- dependency vulnerabilities with a realistic impact on this project.

Scientific algorithm disagreements and normal reproducibility bugs should be reported through GitHub Issues instead.

# Code of Conduct

## Our commitment

This project welcomes participation from people with different backgrounds, experience levels and scientific perspectives. We aim to maintain a respectful, constructive and evidence-based community.

## Expected behavior

- Be respectful and professional.
- Critique ideas, code and scientific methods rather than people.
- Provide reproducible evidence when reporting scientific issues.
- Welcome beginners and explain technical decisions clearly.
- Respect project, data-provider and third-party licensing requirements.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, deliberate disruption, doxxing, or other abusive behavior are not acceptable.

## Enforcement

Project maintainers may remove comments, close issues, or decline contributions that violate these standards. Serious or repeated concerns should be reported privately through the maintainer's GitHub profile or the private security/contact route described in `SECURITY.md`.

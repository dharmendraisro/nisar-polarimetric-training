# QGIS validation checklist

1. Open the Module 09/10 GeoTIFF output in QGIS.
2. Confirm it's in the product's native projected CRS.
3. Compare the layer against the notebook's footprint/AOI plot.
4. Bring in an independent GIS layer and check that it lines up.
5. Apply a reasonable raster stretch before calling it validated.

Official NISAR QGIS guide: https://hyp3-docs.asf.alaska.edu/nisar-docs/using-qgis/

# Data and Reproducibility

## NISAR products

NISAR HDF5 products are intentionally not included in this repository. Users should obtain appropriate products through the official data distribution mechanisms and follow the terms that apply to those products.

## Reproducible issue reports

When reporting a result, record:

- product identifier/name where disclosure is permitted
- product level and mode
- frequency
- processing/product version
- selected AOI and spatial subset
- module and notebook section
- software release version
- environment information
- expected/reference result.

Do not upload restricted data, credentials or very large mission products to GitHub Issues or pull requests.
